# MathLang – Официальная инструкция

**Версия:** 1.0  
**Расширение файлов:** `.math`  
**Интерпретатор:** Python 3

MathLang — это простой язык программирования для математических вычислений. Он поддерживает переменные, встроенные математические функции, пользовательские функции и арифметические операции.

## Быстрый старт

1. Установите Python 3.6 или выше.
2. Скачайте `mathlang.py`.
3. Создайте файл с расширением `.math`.
4. Запустите: `python mathlang.py имя_файла.math`

## Что делает каждая команда?

| Команда | Что делает | Пример |
|---------|------------|--------|
| `=` (присваивание) | Сохраняет значение в переменной | `x = 5` |
| `print` | Выводит результат выражения | `print x + 2` |
| `func имя(параметр) = выражение` | Определяет пользовательскую функцию | `func sqr(a) = a^2` |
| `#` | Комментарий (игнорируется) | `# это комментарий` |

## Операции

- `+` сложение
- `-` вычитание
- `*` умножение
- `/` деление
- `^` возведение в степень (правоассоциативно)

## Встроенные функции

Все функции принимают **один аргумент**:

| Функция | Описание |
|---------|----------|
| `sin(x)` | Синус (радианы) |
| `cos(x)` | Косинус |
| `tan(x)` | Тангенс |
| `sqrt(x)` | Квадратный корень |
| `log(x)` | Натуральный логарифм |
| `exp(x)` | Экспонента (e^x) |
| `abs(x)` | Модуль |
| `floor(x)` | Округление вниз |
| `ceil(x)` | Округление вверх |
