# MathLang – математический язык программирования

## Возможности
- Арифметика: `+ - * / ^`
- Встроенные функции: `sin, cos, tan, sqrt, log, exp, abs, floor, ceil`
- Переменные и пользовательские функции (с одним аргументом)
- Файлы `.math`

## Быстрый старт
```bash
git clone https://github.com/ваш_username/mathlang.git
cd mathlang
python mathlang.py examples/test.math
